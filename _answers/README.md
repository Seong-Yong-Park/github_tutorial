# 정답지

**각 Stage에서 파일을 직접 만든 다음에만 열어보세요.**

먼저 보면 손이 기억하지 못합니다. 15분 시도해보고 안 되면 그때 열어도 늦지 않습니다.

| 폴더 | Stage | 내용 |
|---|---|---|
| `stage1/` | 1 | 이슈 생성을 CLI로 하는 법 (UI로 먼저 해본 뒤 비교) |
| `stage2/` | 2 | PR 템플릿, NaN 버그 수정본 |
| `stage3/` | 3 | CI 워크플로, 이슈 폼 2종, add-to-project |
| `stage5/` | 5 | CODEOWNERS |
| `stage6/` | 6 | Notion 동기화 워크플로 + 스크립트 + 세팅 순서 |
| `stage7/` | 7 | .repos, 릴리스 매니페스트, 재사용 워크플로 |

Stage 4와 8은 파일이 아니라 **GitHub UI 조작**과 **문서 작성**이라 정답지가 없습니다.
